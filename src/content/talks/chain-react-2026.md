Most conversations about LLMs in development focus on code generation. This talk explores what becomes possible when agents can instead observe and interact with a running React Native application through its existing debugging surface.

Using Rozenite for Agents and Agent Device, agents connect to React Native DevTools, communicate with custom plugins, navigate user flows, investigate bugs, and validate UI and state changes in real time. The result is a larger, more autonomous development loop operating within boundaries defined by the tooling.
