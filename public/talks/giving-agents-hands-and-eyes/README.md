# Giving Agents Hands and Eyes in React Native

Open `index.html` in a browser or serve this directory with any static file server.

## Controls

- Right arrow, space, or Page Down: next slide
- Left arrow or Page Up: previous slide
- Home / End: first or last slide
- `F`: fullscreen
- `O`: slide overview

Image and video placeholders are intentionally labeled in the deck so production assets can be swapped in later.

The deck bundles Alliance No.2 for headings, Switzer Variable for body copy, and Fira Code for code and monospace UI.
